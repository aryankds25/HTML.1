QR Code Encoder & Decoder
A simple Python-based application to generate and decode QR codes. Users can enter text, URLs, or contact information and generate a QR code image that can be saved and shared.

Features
Generate QR codes from text or URLs
Save QR codes as PNG images
Simple and user-friendly interface
Decode QR codes from images
Webcam-based QR code scanning
Contact information support
Technologies Used
Python
qrcode – QR code generation
Pillow (PIL) – Image processing
Tkinter – GUI
Installation
pip install qrcode pillow opencv-python
How to Run
python main.py
Enter your text or URL, generate the QR code, and save it as an image.

Project Objective
To develop a Python application that demonstrates QR encoding, decoding, image processing, and data handling.

Future Scope
Contact/vCard QR generation
Live webcam scanning
Improved GUI
QR history and management
